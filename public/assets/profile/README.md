# Profile photo

Place the downloaded profile photo here as:

  profile.jpg  (or profile.png)

The portfolio is designed to work without a photo (monogram visual in the
hero), so this is optional. If you add `profile.jpg` here, reference it from
the Hero/About components.

No Google Drive URL was provided in an automatically downloadable form, so no
external photo was hot-linked — add the file locally to keep GitHub Pages
fast and private.
